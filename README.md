# 🏆 Proyecto 2: FIFA World Cup 2026 - Player Performance & Scouting Analytics
**Descripción:** Análisis de rendimiento y scouting de la Copa Mundial 2026. Este proyecto abarca desde el Análisis Exploratorio de Datos (EDA) utilizando **Python (Pandas)**, hasta el modelado dimensional, optimización del motor **VertiPaq** y análisis de rendimiento de consultas con **DAX Studio** en **Power BI**.

## Estructura del Repositorio

* *Data/*: Almacena los datasets originales base para el análisis, en este caso, fue obtenido a través de la plataforma de kaggle.
* *Reports/*: Contiene el archivo final del dashboard interactivo en Power BI (.pbix).
* *Source/*: Contiene los Jupyter Notebooks con el código en Python para el proceso ETL para limpieza y análisis exploratorio del archivo.

## 📂 Estructura del Repositorio
* `/Data`: Almacena el dataset original extraído de Kaggle (FIFA World Cup 2026 Player Performance).
* `/Source`: Contiene los Jupyter Notebooks (`.ipynb`) con el código en Python para el Análisis Exploratorio de Datos (EDA) y la limpieza (ETL).
* `/Reports`: Contiene el archivo final del dashboard interactivo en Power BI (`.pbix`).

## 🛠️ Tecnologías y Herramientas Utilizadas
* **Python (Pandas, Matplotlib & Seaborn):** Procesamiento, validación de calidad de datos y análisis exploratorio (EDA).
* **Power BI:** Modelado dimensional (Esquema de Estrella), diseño de interfaz de usuario (UX) avanzada, Marcadores y KPIs.
* **Optimización y Rendimiento:** Motor VertiPaq y DAX Studio.
